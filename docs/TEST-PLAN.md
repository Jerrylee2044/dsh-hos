# DSH HOS 0.2.3 测试方案

## 1. 测试目标

验证 DSH HOS 自研 HarmonyOS 运行时在真机上可正常启动、登录、对话、会话持久化、终端和设置功能，且不依赖 Pocket/IEC 运行时。

## 2. 测试环境

| 项 | 值 |
|---|---|
| 设备 | HUAWEI 畅享 90 / JUY-AL80 |
| 系统 | HarmonyOS 7 |
| 应用版本 | v364 / 0.2.3-alpha.2-matexts.294 |
| DSH 引擎 | @deepseek-ai/dsh 0.2.3-alpha.2 |
| Node | 24.22.1，自研入口 dsh_node_main |
| 网络 | 移动数据 / Wi-Fi |
| 安装包 | 自研 release HAP，调试签名 |

## 3. 范围与不在范围

覆盖：启动、安全区、登录、账号、模型、对话、流式输出、会话保存、工作区、设置、关于、终端、外部链接、前后台、重启。

不在范围：Mate XTs 折叠形态回归；正式商店签名；多用户并发；长期稳定性压测。

## 4. 用例

### A. 启动与基础界面

| ID | 步骤 | 预期 |
|---|---|---|
| A1 | 冷启动应用 | 显示 DSH HOS 启动页，随后进入 DSH Web |
| A2 | 检查状态栏/安全区 | 内容不被系统状态栏、导航条遮挡 |
| A3 | 检查版本 | 设置/关于显示 0.2.3-alpha.2 |
| A4 | 切换浅色/深色 | 壳层与 Web 跟随系统，无白块/黑块 |
| A5 | 返回/重进应用 | 不重建运行时，Web 保持可用 |

### B. 登录与账号

| ID | 步骤 | 预期 |
|---|---|---|
| B1 | 未登录时打开应用 | 显示登录/API Key 引导，不白屏 |
| B2 | 点击登录 | 自动打开系统浏览器登录页，不白屏 |
| B3 | 完成账号授权后返回应用 | 自动显示已登录，账号/余额可读 |
| B4 | 打开设置→账号与余额 | 头像、手机号、余额正常 |
| B5 | 退出登录再登录 | 流程可重复，不崩溃 |

### C. 模型与会话

| ID | 步骤 | 预期 |
|---|---|---|
| C1 | 选择工作区 home | 显示输入框和模型选择 |
| C2 | 发送简单消息 `hi` | 流式返回，状态为完成 |
| C3 | 多轮追问 | 上下文保持 |
| C4 | 发送需要工具的消息 | 工具调用可见，结果返回 |
| C5 | 新建会话 | 会话列表新增 |
| C6 | 重启应用 | 历史会话仍在，内容可打开 |
| C7 | 切换会话 | 内容/工作目录正确切换 |

### D. 设置与关于

| ID | 步骤 | 预期 |
|---|---|---|
| D1 | 打开设置 | 显示设置标签，无布局溢出 |
| D2 | 切换各设置标签 | 内容正常，不崩溃 |
| D3 | 设置→关于 | 独立关于页，透明 logo、版本、链接正常 |
| D4 | 点击关于内链接 | 系统浏览器打开对应页面 |
| D5 | 外部链接（会话内） | 不覆盖 DSH Web，返回后仍可用 |

### E. 终端与命令

| ID | 步骤 | 预期 |
|---|---|---|
| E1 | 打开右侧终端 | ArkTS 终端出现 bash 提示符 |
| E2 | 执行 `pwd` / `echo` | 输出正确 |
| E3 | 执行 `ls` / `git --version` | 内置命令/工具可用 |
| E4 | Ctrl-C/Ctrl-D | 中断/退出行为合理 |
| E5 | 关闭再打开终端 | 会话可重建，不崩溃 |

### F. 稳定性与异常

| ID | 步骤 | 预期 |
|---|---|---|
| F1 | 切后台 1 分钟后返回 | 运行时不退出，Web 可恢复 |
| F2 | 断网后发消息 | 显示错误，不崩溃；恢复网络后可重试 |
| F3 | 强杀应用后冷启动 | 正常解包/启动，无重复崩溃 |
| F4 | 连续打开/关闭设置、关于 | 无内存暴涨/白屏 |
| F5 | 查看 hilog | 无 SIGSEGV/SIGSYS/未处理异常 |

## 5. 通过标准

- A/B/C/D/E 全部关键用例通过；
- 无启动白屏/黑屏；
- 登录与对话可用；
- 会话可持久化；
- 终端可用；
- 无 Pocket/IEC 入口；
- F 类问题有记录且不阻断使用。

## 6. 记录方式

每条用例记录：通过/失败、截图或日志、复现步骤、实际现象。失败项进入修复清单并重测。
